## 公開方法（GitHub Pages）

1. このリポジトリを GitHub で作成
2. 全ファイル・フォルダをアップロード
3. Settings → Pages → Branch: `main` / folder: `/ (root)` に設定
4. `https://ユーザー名.github.io/リポジトリ名/` で公開
